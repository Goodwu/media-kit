# 当前工作树 HDR10 原生 SurfaceView 复验（2026-09-25）

在华为 LYA-AL00 Android 10/API29，当前工作树构建 versionCode 11050（APK SHA-256 `785ca1e3481fa7d7b0eb6c0eb9e5280560523f563ee3cacebd2ff3469ba06f3f`），开启 HDR transaction、PlatformView 和固定 Android 本地源，未开启 GPU Platform HDR 实验。策略选择原生 `mediacodec_embed`/`mediacodec` 路线；**没有在打开后单独回读 VO 字符串**，故实际执行证据以硬解输出、视频 Surface 层和 dataspace 为准。输入 `/data/local/tmp/media-kit-hdr10-full.mp4` 已登记 SHA-256 `e4f869b140e3ef322b7fc63fefe015593708f6443fc79060fa3e7f2234816937`；ffprobe 为 HEVC Main10、3840×1920、30000/1001 fps、BT.2020nc/PQ、约304.77秒，首帧静态 metadata 含1000 nit mastering、0.0001 nit min、MaxCLL/FALL 均0。

`ANDROID_HDR_OPEN` 报 `sample=hdr10`、`presentationVerified=false`、`gpuPlatformHdr=false`。输出参数回报 `pixelformat=mediacodec`、BT.2020 limited/PQ；ACodec 使用 `OMX.hisi.video.decoder.hevc`，最终 color aspects BT2020/BT2020/ST2084、dataspace `0x11c60000`。SurfaceFlinger 的活动 `SurfaceView - ...MainActivity#1` buffer 3840×1920、vendor format 325；该层 `dataspace=BT2020_ITU_PQ (298188800)`、`hdr metadata types=3`，视频可见区域 `[0,326,1440,1136]`，HWC `composition=DEVICE`。厂商日志最终记 `MaxLum=1000, MinLum=1, MaxCLL=0, MaxFALL=0`，与本源首帧值一致；SF 只报告 metadata 类型，不能从此证明显示器实际亮度或严格 HDR10 合规。

活动层 frame-counter 在同一 PID 的三次系统采样（主机 monotonic 秒）依次 `699236.539→4282`、`699241.637→4435`、`699246.744→4589`，间隔约5.1秒各增153/154，约30 buffer/s。它表明该窗口 SurfaceFlinger 持续接收视频 buffer，不是逐帧物理 present。相隔约3秒的两张整屏截图，视频 ROI RGB 原始字节 SHA-256 分别为 `2ccf50aa502041f8b6b1a5bf7b2ccf414a4d2975170b317f719832448511251a` 和 `d4dfffcc69383128b2483ec236ea7b5408d96695634a03b40474452bed9c335b`；说明采样到的画面不同，但 Android 截图为 SDR 映射，不能据此判断 HDR 高光、颜色准确或真人可见流畅度。

结果仅支持**当前工作树原生 HDR10 路线在本机建立 PQ/HDR metadata 视频层并持续提交约30fps buffer**。尚缺显示器当前 HDR 状态/实测亮度、全长稳定性、严格逐帧 present/声画同步与人工颜色验收；不能替代计划 T1 的 gpu-next→PlatformView PQ 输出。设备运行后已强停并恢复10369基线包，`debug.media_kit.window_hdr_mode=0`，无应用进程。日志、SF dump、采样和截图在 `artifacts/android-hdr10-direct-11050/`；SHA-256：`logcat.txt` `fb19914993809f177bac0b77bc1366071e85e248a7d4f3467364142d5320f60d`，`surfaceflinger.txt` `847b7c55902f1c5f8fd69c0cec710a318b1f0cb17d072eefc2eef7e39b42af15`，`counter-window.txt` `2eda0b49d05d4d1a1140f246b6e37beacbcaf29af6af3e3cba2264393e701a73`，`screen-a.png` `b1a979c9f1df21ce7a76d38b1d439c948c715fd86dd07458f9104ff64fa999bf`，`screen-b.png` `cfb5d20fcdcc8aac658e0ba53ec4b82483eeb3ef27f5d20c207c3e4beb1b0db1`。
