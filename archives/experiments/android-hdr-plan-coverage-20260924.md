# Android HDR/DV 计划验收矩阵覆盖核对

依据 [总计划的最小验证矩阵](../conversations/android-hdr-dv-display-plan-20260922.md) 核对当前源码与 APK。下表的“候选”仅代表离线实验入口，不代表设备或可见验收通过。2026-09-24 当前九包均未安装或运行。

| 计划格 | 当前候选/证据 | 当前结论 |
| --- | --- | --- |
| C0 SDR 双视图与复位 | 既有 4154 SDR 恢复基线；新版循环尚未运行；新增确定编码的 SDR 灰阶阴性输入 | 新事务复位未验收，灰阶未传设备 |
| C1 原生 HDR10 阳性对照 | 既有 2157 原生播放观察；6233 为新版事务直出；新增确定编码的 PQ 灰阶阳性输入 | 新版未运行；HDR 激活仍缺显示链证据 |
| T1 HDR10 gpu-next→PlatformView PQ | 默认路线 6233 为直出；新增默认关闭的专用 6237 GPU PQ 候选 | 离线候选；设备 dataspace 曾 `-22`，首帧及显示未验收 |
| T2 P8.4 忽略 DV、gpu-next→PlatformView HLG | 默认路线 6236 为直出；新增默认关闭的专用 6238 GPU HLG 候选 | 离线候选；RPU 未实际应用、像素、HLG显示均未验收 |
| T3 P8.4 HLG→PQ | 6235 明确模拟无 HLG、选 gpu-next/PQ | 离线候选；真实无 HLG 设备仍缺 |
| T4 P5 RPU 处理→PlatformView PQ | 6234 带 P5 属性门禁与 gpu-next/PQ | 离线候选；逐帧处理、像素和显示仍缺 |
| S1/S2/S3 HDR10/P8.4/P5→Texture SDR | 6230/6231/6232 | 离线候选；三格均待实机与人工可见验收 |
| C2 同源原生与 GPU 对照 | HDR10 6233/6237 为同源不同后端；P8.4 6236/6238 为同源 HLG 不同后端 | 候选齐备，均未设备对照；软解分支缺 |
| C3 能力异常与失败关闭 | 策略单测覆盖缺能力与部分条件 | 主机策略测试通过，设备异常路径未运行 |
| E1 P8.1/P7 | 当前无对应固定素材 | 后续扩展，未验收 |
| E2 原生 DV | 本机无匹配能力证据 | 独立扩展，未验证 |

计划还要求 P1 的已知 PQ/HLG 阳性与 SDR 阴性、同层显示状态及独立颜色参考；P5 要求 DV 元数据实际消费和像素参考；P5 稳定性要求每样本多次冷启/重开、60 秒/10 分钟/至少 30 分钟、seek/暂停/旋转/后台/退出循环。现有 APK 身份、静态测试、旧版用户观察均不足以证明这些门禁。任何不可观测的显示激活或颜色正确性应记 `INCONCLUSIVE`。
