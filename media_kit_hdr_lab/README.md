# media_kit_hdr_lab

HDR/DV 诊断 App（P2-4 整改自 media_kit_test 拆分）：承载 AUTO/HDR dart-define 面、
Android HDR 播放策略与输出槽协调器、P5 解码/GPU/native reader 探针、LYA 厂商
dataspace 扩展与设备能力通道、engine 销毁验收通道。实机轮次脚本（`tool/matrix-*`、
`merge-accept-*`、`decode-probe-round`）以本 App 为目标（包名
`com.example.media_kit_hdr_lab`）。`media_kit_test` 已还原为上游示例 App。
